# NICAM 云微物理加速研究需求

面向 ANZIAM 2027，从 NICAM NSW6 云微物理的实际计算瓶颈出发，找到一个有数学内容、能够解释加速来源的优化思路，并把它实现为可运行的高性能算子。项目以提高实际运行速度为目标，数学方法的选择由源码和实验决定。

## 研究要回答的问题

1. **时间花在哪里？** 在 Miyabi-G 建立可复现的原始版本基线，找出最影响一次微物理调用的计算，同时记录当前优化版本的表现。
2. **哪些工作可以少做？** 从实际算子中提炼数学结构，说明它为什么允许减少计算或数据搬运、适用于哪些输入。允许尝试近似方法，明确精度与速度之间的取舍。
3. **这个想法如何变成真实加速？** 把方法接入 NICAM 的实际调用路径，在相同硬件、输入和计时口径下比较原始版本、已有优化和新增优化。分别报告单算子与整个微物理步的耗时。
4. **天气计算受了什么影响？** 用相同初始状态比较水物质、温度和累计降水等相关输出，检查连续时间步中的误差。按验证范围表述结论；涉及预报效果时，给出耦合天气个例的证据。

## 交付与论文主线

保留可独立恢复的原始源码、可复现的优化源码，以及版本、配置、输入标识、原始计时和数值对照。论文从一个具体天气计算问题写起，依次说明实测瓶颈、数学依据、算子实现和实验结果，最后回答每步实际省了多少时间、付出了什么精度代价，以及结论适用于哪些情形。
